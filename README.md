# Ezzygo

Full-stack application built with React, Vite, Tailwind CSS v4, Node.js, Express, and MongoDB.

## Project Structure

```
Ezzygo/
├── frontend/    # Vite + React (TypeScript) + Tailwind CSS v4
└── backend/     # Node.js + Express + MongoDB (Mongoose)
```

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
